# AI 스터디메이트

공부를 도와주는 학습 앱. PC와 폰에서 같이 씁니다.

## 실행

Windows에서 **`웹앱 실행.bat`** 을 더블클릭하면 브라우저가 열립니다.

직접 실행하려면:

```sh
pip install flask
python web/app.py
```

켜지면 검은 창에 주소 두 개가 뜹니다.

| | 주소 |
|---|---|
| PC | `http://127.0.0.1:5000` |
| 폰 | `http://<PC의 내부 IP>:5000` (PC와 같은 와이파이) |

폰 브라우저에서 **홈 화면에 추가**하면 앱처럼 열립니다.
브라우저를 모두 닫으면 서버가 스스로 종료되고(약 60초), 홈 화면의 **앱 종료**로 바로 끌 수도 있습니다.

## 계정

- **계정 만들기** — 이름 · 생년월일 · 학교(초/중/고)와 학년 · 아이디 · 비밀번호
- **로그인 유지** 30일
- **비밀번호 재설정** — 아이디 + 생년월일로 본인 확인 후 새로 지정 (5회 틀리면 10분 잠김)
- 비밀번호는 되돌릴 수 없게 암호화해 저장합니다
- 계정별로 문제·계획·기록이 완전히 분리됩니다
- **비밀번호 변경** — 홈 아래 `계정 설정`. 지금 비밀번호를 먼저 확인합니다
- **계정 삭제** — 같은 화면에서. 문제·오답·계획·기록이 **함께 지워집니다**
  (관리자 계정은 지울 수 없고, 관리자는 `계정 관리`에서 남의 계정을 지울 수 있습니다)

## 등급

계정은 세 가지로 나뉩니다.

| 등급 | 한도 | 기간 |
|---|---|---|
| **관리자** | 없음 | 없음 |
| **회원** | 없음 | 결제한 날부터 30일 — 지나면 비회원으로 돌아갑니다 |
| **비회원** | 과목마다 하루 5번 풀기 · AI 질문 하루 10번 (**문제 만들기는 제한 없음**) | — |

새 계정은 **비회원**으로 시작합니다. 기간이 지나면 따로 무엇을 하지 않아도
그날부터 한도가 다시 생기고, 관리자 목록에는 **기간 지남**으로 표시됩니다.

## 결제

홈에서 등급 칩(`비회원` / `회원 · 12일 남음`)을 누르면 결제 화면이 열립니다.
1개월 · 3개월 · 1년 중에 고르면 신청이 만들어집니다.

**결제사는 아직 정하지 않았습니다.** 지금은 관리자가 입금을 확인하고 `계정 관리`
화면의 **입금 확인**을 눌러 승인합니다. 결제사를 붙이면 이 단계가 없어집니다.

첫 결제도 기간 연장도 **같은 길**(`apply_payment`)을 지나갑니다. 기간이 남아
있으면 남은 기간 **뒤로 이어 붙고**, 같은 결제가 두 번 들어와도 기간이 두 번
늘지 않습니다.

**자동 갱신**을 켜 두면 기간이 3일 남았을 때 갱신 신청이 저절로 만들어집니다.
다만 **14일 넘게 앱을 쓰지 않았으면 건너뜁니다** — 안 쓰는데 돈만 빠져나가지
않게 하려는 것입니다. 다시 쓰기 시작하면 그때부터 이어집니다.

### 결제사를 붙일 때

`web/app.py` 의 **`verify_payment()` 한 곳만** 채우고 `PAYMENT_PROVIDER` 를 바꾸면
회원 전환·기간 연장·자동 갱신이 모두 저절로 됩니다. 이 함수는 결제사에
"이 주문 돈이 들어왔나요?" 하고 물어서 `True`(결제됨) / `False`(취소) /
`None`(아직 모름) 을 돌려주면 됩니다.

앱을 열 때마다 서버가 이 함수로 확인하므로(**조회 방식**), 집 PC에서 돌려도
결제가 자동으로 반영됩니다. 서버를 인터넷에 올린다면 결제사가 직접 알려 주는
**웹훅**(`POST /api/billing/webhook`) 자리도 만들어 두었습니다 — 서명 확인만
채우면 됩니다.

## 화면

| 화면 | 내용 |
|---|---|
| **문제 풀기** | 과목을 고르고 문제를 풀어 바로 채점. 띄어쓰기·대소문자는 무시. 문제는 하나씩 또는 **여러 개 한 번에** 넣습니다 |
| **문제 기록** | 푼 문제를 **오답 · 다시 맞힘 · 한 번에 맞힘**으로 나눠 봅니다. 잊을 만할 때 다시 내주는 **복습**도 여기 있습니다 |
| **학습 계획** | 하루 시간표를 적고 체크. 과목을 고르면 **바로 풀러 가고, 풀면 저절로 체크**됩니다. **되풀이**로 둘 수 있고, 시험일을 정하면 D-day. 아래에 **공부 기록**이 함께 있습니다 |
| **AI에게 질문** | 질문을 적어 보내면 기록됩니다 (AI 답변은 아직 연결 전) |
| **계정 관리** | 관리자만 보입니다. 가입한 계정을 등급별로 보고 회원 기간을 정합니다 |

홈에는 오늘 날짜와 시계가 있고, **폰 / PC 보기**를 고를 수 있습니다(넓은 화면은 자동).

**색·밝기 바꾸기** — 홈 아래 `계정 설정` 안에서 앱 색과 **밝게/어둡게**를 고릅니다.
밝기는 `기기 설정 따르기`가 기본이라, 폰이 어두운 모드면 앱도 어두워집니다. 미리 담긴 일곱 가지
중에 고르거나 색판에서 직접 정할 수 있고, 고른 색은 계정에 저장되어 PC와 폰이
같은 색을 봅니다. 색 하나만 정하면 배경·버튼·글씨색이 모두 따라 바뀝니다
(`web/static/style.css` 의 `--brand`).

## 풀었던 문제 찾기

문제가 쌓이면 목록을 눈으로 훑어서는 못 찾습니다. `문제 풀기` 첫 화면에서
낱말로 찾습니다.

- **문제 · 정답 · 해설** 어디에 있든 찾습니다. 띄어쓰기와 대소문자는 무시
- 과목으로 좁히거나 **틀린 문제만** 볼 수 있습니다
- **푼 날짜**로도 찾습니다. 채점할 때마다 그 날짜가 남습니다
- **날짜가 기억나지 않으면 비워 두세요** — 꼭 맞는 것이 없어도 **비슷한
  문제**를 함께 찾아 줍니다. 같은 낱말이 얼마나 겹치는지, 글로 미루어 어느
  과목인지(`SUBJECT_HINTS`)를 함께 봅니다
- 찾은 문제는 바로 **풀기**를 눌러 그 문제만 풀 수 있습니다

예를 들어 `미분`으로 찾으면 그런 문제가 없어도 수학 문제들이 나옵니다.

## 문제 여러 개 한 번에 넣기

`문제 추가 → 여러 개 한 번에` 에서 한 줄에 하나씩 적습니다.

```
3의 제곱은? / 9
물의 화학식은? / H2O / 수소 둘에 산소 하나
2+2 , 4
광합성이란?	식물이 빛으로 양분을 만드는 일
```

- 가르는 글자는 `/` · 쉼표 · 탭 어느 것이나 됩니다. 세 번째 칸은 해설입니다
- 빈 줄과 `#` 로 시작하는 줄은 넘어갑니다. 한 번에 100줄까지
- 못 읽은 줄은 **몇 번째 줄이 왜 안 됐는지** 알려 주고, 읽은 것만 들어갑니다
- 문제를 만드는 데는 하루 제한이 없습니다 (한 사람당 500문제까지)
- `기타`에 넣으면 글을 보고 과목을 짐작합니다

## 공부 기록

학습 계획 화면 아래에 있습니다.

- **오늘** — 푼 문제 · 맞힌 문제 · 복습 · 해낸 계획 · 공부한 시간
- **연속 학습 일수** — 며칠을 이어서 공부했는지
- **최근 2주 막대** — 옅은 칸이 푼 문제, 진한 칸이 맞힌 문제
- **과목별 정답률** — 최근 30일, **낮은 과목이 위로** 옵니다 (60% 아래는 빨강)

날짜별 기록은 `stats.json` 에 쌓입니다(한 해 남짓 보관). `usage.json` 은 오늘
것만 담고 날짜가 바뀌면 지워지므로, 지난 기록은 여기에 따로 남깁니다.

## 과목

과목은 **사람마다 다릅니다.** 학교급에 맞는 기본 과목으로 시작해서, `과목 편집`에서 이름과 하루 횟수를 바꾸거나 새로 추가할 수 있습니다 — 과학이 물리학·화학으로 갈라지는 경우처럼요.

- **하루 횟수는 과목마다 따로**입니다 (0으로 두면 무제한)
- **회원과 관리자는 무제한**입니다
- 비회원은 이 값을 크게 잡아도 **한 과목 하루 5번**을 넘지 못합니다
  (`GUEST_SOLVE_LIMIT`). 스스로 더 낮게 두는 것은 그대로 지켜집니다
- 과목을 지우면 그 과목의 문제는 **기타**로 옮겨집니다

**복습은 세지 않습니다.** 오답 노트에 있는(마지막에 틀린) 문제를 다시 푸는
것은 횟수를 쓰지 않고, 오늘 몫을 다 썼어도 언제든 할 수 있습니다. 틀린 것을
다시 보는 일까지 막으면 공부를 막는 셈이기 때문입니다. 복습인지 아닌지는 화면
말을 믿지 않고 **서버가 정합니다**.

## 시험까지 계획 짜 주기

`학습 계획 → 시험일 정하고 계획 짜기` 에서 시험 이름·날짜와 함께 하루 공부
시간·시작 시각을 고르고 저장하면, **시험일과 시간표가 한 번에** 만들어집니다.
계획은 빼고 날짜만 정하고 싶으면 `시험까지 공부 계획도 함께 짜기` 를 끄면 됩니다.

- **약한 과목에 시간을 더 줍니다.** 최근 30일 정답률이 낮을수록, 오답이
  많을수록 무겁게 봅니다. 아직 풀어 본 적 없는 과목은 가운데쯤으로 둡니다
- 하루에 다루는 과목 수를 줄여(한 과목에 35분쯤) 시간이 골고루 흩어지지 않게 합니다
- 만들어진 계획은 **시험일까지 되풀이**되고, 시험이 지나면 저절로 사라집니다
- 다시 짜면 전에 자동으로 짠 것만 걷어 냅니다 — **직접 적은 계획은 그대로**입니다
- 시험일을 지우면 그 시험까지 짜 둔 계획도 함께 치웁니다

### 공부 시간 재기

시험 계획을 짜면 계획마다 **시간 재기**가 붙습니다(직접 적은 계획에는 없습니다).

- `▶ 시간 재기` 를 누르고 공부한 뒤 `■ 그만` 을 누르면 잰 시간이 적힙니다
- 계획에 적힌 시간을 채우면 **저절로 체크**됩니다 (`15 / 40분` → 다 채우면 완료)
- 잰 시간은 공부 기록의 **공부한 시간**에 쌓이고, 날이 바뀌면 다시 0부터입니다
- 1분이 안 되면 적지 않습니다

## 되풀이하는 계획

계획을 적을 때 **반복**을 고르면 날마다 다시 적지 않아도 됩니다.

| 고르기 | 언제 보이는지 |
|---|---|
| 반복 안 함 | 늘 보이고, 끝내면 그대로 남습니다 |
| 매일 | 날마다 |
| 평일 (월~금) | 토·일에는 보이지 않습니다 |
| 매주 같은 요일 | 만든 요일에만 |

되풀이하는 계획은 **날마다 체크가 새로 시작**됩니다. 어제 끝냈어도 오늘은 다시
할 일로 뜹니다. 끝낸 날은 90일치까지 남습니다.

## 문제 기록

한 번이라도 푼 문제가 모두 모입니다. 상태로 나눠 볼 수 있습니다.

| 상태 | 무엇 |
|---|---|
| **오답** | 마지막에 틀린 문제. 복습 대상입니다 |
| **다시 맞힘** | 틀렸다가 다시 풀어서 맞힌 문제 |
| **한 번에 맞힘** | 한 번도 안 틀리고 맞힌 문제 |

오답이 맨 위(오늘 볼 것부터)에 오고, 그다음은 최근에 푼 순서입니다. 과목으로
더 좁힐 수 있고, 문제마다 `2026-09-18에 품 · 3번 풀어 1번 틀림` 처럼 기록이
붙습니다. `이 목록 풀기` 를 누르면 **지금 보고 있는 것만** 풉니다.

아직 안 푼 문제는 여기 나오지 않습니다 — 그것은 `문제 풀기` 에 있습니다.

## 복습

사람은 시간이 지나면 잊어버립니다. 그래서 틀린 문제를 **잊을 만할 때** 다시
내줍니다.

```
틀림 → 오늘 → (맞히면) 1일 뒤 → 3일 뒤 → 7일 뒤 → 14일 뒤 → 졸업
                (틀리면 언제든 처음으로)
```

오답 노트를 열면 맨 위에 **오늘 복습할 문제 N개**와 `복습 시작` 버튼이 있고,
목록에는 문제마다 `내일 복습 · 복습 1 / 4` 처럼 다음에 볼 날이 붙습니다.
오늘 볼 것이 맨 위로 오고, 자주 틀린 것이 그다음입니다.

네 번을 이어서 맞히면 오답 노트에서 **졸업**합니다. 간격은 `web/app.py` 의
`REVIEW_STEPS` 에서 바꿉니다.

### 횟수를 어느 과목에서 뺄지

1. 과목을 골라 넣은 문제 → **그 과목**에서 1회
2. **기타**에 넣은 문제 → 문제 글의 낱말을 보고 **과목을 짐작**해 그 과목에서 1회
3. 그 과목을 오늘 다 썼으면 → **보관해 둔 과목**에서 1회
4. 둘 다 다 썼으면 → 오늘은 풀 수 없다고 안내

짐작이 틀리면 문제 목록에서 주된 과목을 직접 고르면 됩니다.

## 구조

```
웹앱 실행.bat          실행용
web/app.py             Flask 서버 + API
web/templates/         화면(HTML)
web/static/            스타일, 스크립트, 아이콘
```

기록은 서버에 저장되어 PC와 폰이 같은 내용을 봅니다. 개인 자료(`users.json`,
`admins.json`, `quiz.json`, `plans.json`, `subjects.json`, `usage.json`,
`asks.json`, `payments.json`, `stats.json`, `secret.key`)는 저장소에 올리지
않습니다.

## 설정

`web/app.py` 위쪽 상수로 조절합니다.

| 상수 | 뜻 |
|---|---|
| `LEVELS` / `DEFAULT_SUBJECTS` | 학교급과 학교급별 기본 과목 |
| `SUBJECT_LIMIT` | 새 과목의 기본 하루 횟수 |
| `ASK_DAILY_LIMIT` | 비회원의 AI 질문 하루 횟수 |
| `MAKE_DAILY_LIMIT` | 문제 만들기 하루 횟수 (`0` = 제한 없음) |
| `AI_MAKE_DAILY_LIMIT` | 나중에 AI가 출제할 때의 하루 횟수 |
| `GUEST_SOLVE_LIMIT` | 비회원이 한 과목에서 하루에 풀 수 있는 최대 횟수 |
| `MEMBER_DAYS` | 관리자가 손으로 회원을 켤 때의 기본 기간(일) |
| `PLANS` | 살 수 있는 기간과 가격 |
| `PAYMENT_PROVIDER` | 어느 결제사를 쓸지 (`manual` = 관리자가 입금 확인) |
| `RENEW_BEFORE_DAYS` | 만료 며칠 전에 자동 갱신 신청을 만들지 |
| `IDLE_SKIP_DAYS` | 며칠 안 쓰면 자동 결제를 건너뛸지 |
| `ADMIN_USERS` | 관리자 아이디 — 모든 한도를 무시하고 `admins.json`에 저장 |
| `AUTO_STOP_SECONDS` | 창을 모두 닫고 몇 초 뒤에 서버를 끌지 (`0`이면 안 끔) |
| `SUBJECT_HINTS` | 과목을 짐작할 때 쓰는 낱말들 |

환경 변수 `AISTUDY_PORT`로 포트를, `AISTUDY_NO_BROWSER=1`로 자동 브라우저 열기를,
`AISTUDY_DATA_DIR`로 자료 저장 폴더를 바꿀 수 있습니다.
