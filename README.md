# AI 스터디메이트

AI가 공부를 도와주는 학습 앱. PC와 폰에서 같이 씁니다.

## 실행

Windows에서 **`웹앱 실행.bat`** 을 더블클릭하면 브라우저가 열립니다.

직접 실행하려면:

```sh
pip install flask
python web/app.py
```

켜지면 검은 창에 주소 두 개가 뜹니다.

| | 주소 |
|---|---|
| PC | `http://127.0.0.1:5000` |
| 폰 | `http://<PC의 내부 IP>:5000` (PC와 같은 와이파이) |

폰 브라우저에서 **홈 화면에 추가**하면 앱처럼 열립니다.
브라우저를 모두 닫으면 서버가 스스로 종료됩니다(약 60초).

## 화면

- **표지** → **홈** → 카드별 상세 화면
- 홈의 **오늘 사용횟수** 카드는 *문제 만들기* 를 쓸 때만 올라갑니다
- **학습 계획** — 시간(시작~끝)만으로 하루 시간표를 적고 체크. 시험일을 정하면 D-day 표시
- **AI에게 질문** — 화면 위쪽에 오늘 질문 횟수 표시
- **문제 만들기 / 오답 노트** — 아직 화면만 있는 상태

## 구조

```
웹앱 실행.bat          실행용
web/app.py             Flask 서버 + 학습 계획/사용횟수 API
web/templates/         화면(HTML)
web/static/            스타일, 스크립트, 아이콘
```

기록은 서버에 저장되어 PC와 폰이 같은 내용을 봅니다
(`web/plans.json`, `web/usage.json` — 개인 기록이라 저장소에는 올리지 않습니다).

## 설정

`web/app.py` 위쪽 상수로 조절합니다.

| 상수 | 뜻 |
|---|---|
| `DAILY_GOAL` | 홈 카드의 하루 목표 횟수 |
| `HOME_COUNT_KEY` | 홈 카드에 반영되는 카드 (기본: `quiz`) |
| `AUTO_STOP_SECONDS` | 창을 모두 닫고 몇 초 뒤에 서버를 끌지 (`0`이면 안 끔) |

환경 변수 `AISTUDY_PORT` 로 포트를, `AISTUDY_NO_BROWSER=1` 로 자동 브라우저 열기를 끌 수 있습니다.

## 앞으로

AI 연동(문제 자동 출제, 질문 답변)은 아직 붙이지 않았습니다. 지금까지는 비용이 들지 않는 부분만 만들었습니다.
